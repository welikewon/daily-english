2오늘의 문법 (쉽게)

  • 공손하게 원할 때: I'd like ~ (= I would like)
  • 권할 때: Would you like ~? / Would you like to ~?
  • 고를 때(차라리 ~할래요): I'd rather + 동사
  • I'd like 뒤: 물건이면 그냥, 동작이면 to + 동사
  • I'd rather 뒤에는 to 없이 동사
예
물건I'd like a coffee.
동작I'd like to sit here.
권하기Would you like some cake?
차라리I'd rather walk.
I'd rather to eat at home. → I'd rather eat at home. rather 뒤에는 to 없이 바로 동사.

4소리 원리

Would you like some more rice?
🔊 우쥬 라익 썸모어
— d + y → 「쥬」: Would you → 「우쥬」
I'd rather walk.
🔊 아이드 래더 웍
— th 부드럽게: rather · walk의 l은 소리 내지 않아요 → 「웍」
